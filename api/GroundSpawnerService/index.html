GroundSpawnerService

The things that put loot on the ground, and put it back.

Split out of the old GroundItemService, which was three services in one file: the piles themselves, the spawners that create them, and the respawn loop that drives them. GroundItemService kept the piles; this owns the other two.

WHAT CHANGED

The respawn queue was an array (RespawnGroundSpawners) rebuilt from scratch on every pass, with SetModified appending to it under a not State.Modified guard. That guard was the only thing preventing a spawner appearing twice, and it lived at a different call site from the insertion it protected. The queue is a SET keyed by spawner id here, so a duplicate is not something you have to remember to avoid.

Proximity, loot rolling and world placement are all seams:

IsOccupied was SpawnProximityService.Nearby[cell_id], a service that is not ported. Defaults to "nobody nearby", so a spawner respawns freely rather than never. SpawnProvider the loot roll. Defaults to nothing, so an unconfigured spawner spawns nothing rather than erroring. placement goes through GroundItemService, which has its own World seam.

That is what makes the respawn cycle testable: drive Advance directly instead of waiting on a task.wait loop that only exists inside a booted place.

Mark a spawner as needing a respawn.

Called through GroundItemService.OnSpawnerModified whenever one of its piles changes, which is how taking loot puts the spawner back in the queue.

Despawn​

</>
GroundSpawnerService:Despawn(spawner: GroundSpawnerData) → ()

Take back everything this spawner put down.

Only its own piles: a pile that merged into someone else's, or one a player dropped nearby, is not the spawner's to remove. SpawnIds is the record of what it owns.

Spawn​

</>
GroundSpawnerService:Spawn(spawner: GroundSpawnerData) → boolean

Roll and place this spawner's loot.

Returns whether anything was placed. Refuses when the spawner is already spawned and untouched, or when a player is close enough to watch -- items appearing in front of someone is the thing proximity exists to prevent.

Advance​

</>
GroundSpawnerService:Advance() → number

Run one pass over the respawn queue.

A spawner that spawns leaves the queue; one that could not -- a player stood nearby, or its table rolled empty -- stays for the next pass. Returns how many spawned.

The old version rebuilt the queue array each pass and iterated the previous one. Doing it against a set means a spawner modified DURING a pass is still queued at the end of it, rather than being dropped because it was not in the array the pass started with.
