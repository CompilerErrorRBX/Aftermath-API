InventoryManager

A player's set of inventories: pockets, vest, backpack, ground access.

Replaces InventoryManager. The old one kept a list of Inventory objects and re-implemented every query across them; here the per-inventory logic lives in InventoryService and this layer only decides ORDER -- which inventory to fill first, which to search, which to exclude.

Everything remains conservative: an add that does not fit returns the remainder as a stack rather than dropping it.
